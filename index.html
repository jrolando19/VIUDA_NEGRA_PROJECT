Cine Management System

Sistema web de gestión de cine desarrollado para la administración de películas, funciones, reservas y usuarios.

Funcionalidades

🎬 Gestión de Películas

Permite registrar, editar y eliminar películas dentro del sistema.

🕒 Gestión de Funciones

Administración de horarios, fechas y funciones disponibles en el cine.

🎟️ Reserva de Entradas

Los usuarios pueden seleccionar asientos y realizar reservas de entradas.

👤 Gestión de Usuarios

Control de acceso mediante autenticación y administración de clientes.

🏢 Gestión de Salas

Permite organizar las salas de cine y controlar su disponibilidad.

📊 Panel Administrativo

Visualización y control general del sistema desde un panel central.

Documentación del Proyecto

Este proyecto consiste en un sistema de gestión de cine desarrollado con tecnologías web. Su finalidad es facilitar la administración de películas, funciones, reservas y usuarios dentro de una plataforma digital.

🎯 Objetivo del Sistema

El sistema busca optimizar la organización y control de un cine mediante herramientas administrativas y funcionalidades para clientes.

⚙️ Funcionalidades Principales

  • Registro y administración de películas.
  • Gestión de horarios y funciones.
  • Control de salas de cine.
  • Reserva y compra de entradas.
  • Inicio de sesión y autenticación.
  • Panel administrativo.
  • Gestión de usuarios y clientes.
  • Visualización de cartelera.

🛠️ Tecnologías Utilizadas

  • HTML5
  • CSS3
  • JavaScript
  • PHP
  • MySQL
  • Git & GitHub

📌 Flujo General del Sistema

El cliente puede ingresar al sistema, visualizar las películas disponibles, seleccionar funciones, escoger asientos y reservar entradas.

El administrador tiene acceso a módulos de gestión de películas, salas, horarios, usuarios y reportes generales.

📂 Estructura General

  • Frontend: Interfaces visuales del sistema.
  • Backend: Procesamiento lógico y administración.
  • Base de Datos: Almacenamiento de información.

🎓 Finalidad Académica

Este proyecto fue desarrollado con fines académicos para aplicar conocimientos en programación web, bases de datos y gestión de sistemas.
