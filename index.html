InvenTree: plataforma open source para inventario

Este repositorio está dedicado a presentar el proyecto InvenTree. InvenTree es una solución moderna para la gestión de inventario, partes, stock y procesos relacionados con fabricación.

Gestión de partes

Organización de componentes con metadatos, categorías y trazabilidad.

Control de stock

Seguimiento de existencias, ubicaciones y movimientos de inventario.

Flujo de fabricación

Soporte para BOM, órdenes de construcción y procesos de ensamblaje.
