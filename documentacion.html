Descripción General

InvenTree es un sistema Open Source orientado a la gestión de inventario, control de stock y administración de componentes empresariales.

Funcionalidades

  • Gestión de inventario.
  • Control de stock.
  • Gestión de proveedores.
  • API REST.
  • Sistema de usuarios.
  • Plugins y extensiones.

Tecnologías Utilizadas

  • Python
  • Django
  • TypeScript
  • Docker
  • PostgreSQL
