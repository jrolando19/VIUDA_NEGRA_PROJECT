Descripción General

InvenTree es una plataforma Open Source (licencia MIT) de gestión de inventario y manufactura, construida sobre Python y el framework Django. Su diseño orientado a componentes y piezas lo hace especialmente adecuado para laboratorios electrónicos, talleres de manufactura, startups de hardware y cualquier organización que requiera trazabilidad precisa de materiales.

A diferencia de ERPs genéricos, InvenTree no intenta cubrir contabilidad, nóminas ni CRM — se especializa exclusivamente en la cadena: parte → stock → proveedor → orden → manufactura, lo que lo convierte en una herramienta muy eficiente y enfocada.

Arquitectura del Sistema

InvenTree sigue una arquitectura de tres capas clásica, con separación clara entre presentación, lógica de negocio y persistencia de datos. El backend expone toda su funcionalidad vía API REST, lo que permite desacoplar completamente el frontend.

Frontend — React SPA

Aplicación de página única construida con React y TypeScript. Usa la librería de componentes Mantine para la UI.

  • React 18 + TypeScript
  • Mantine UI Components
  • React Query (data fetching)
  • React Router (navegación)
  • Axios (cliente HTTP)

Backend — Django + DRF

Núcleo del sistema. Django gestiona modelos, autenticación, permisos y lógica de negocio. DRF expone la API.

  • Django 4.x ORM
  • Django REST Framework
  • Token + Session Auth
  • Celery (tareas en background)
  • Sistema de plugins

Infraestructura

Capa de datos y servicios de soporte. Despliegue completo disponible mediante Docker Compose.

  • PostgreSQL (producción)
  • Redis (caché y broker)
  • Nginx (reverse proxy)
  • Docker + Compose
  • Almacenamiento de archivos

Módulos Principales

El sistema está organizado en módulos Django independientes, cada uno responsable de un dominio funcional específico del proceso de inventario y manufactura.

📦

Part — Gestión de Partes

Módulo central del sistema. Una Part representa cualquier componente, pieza o producto que se quiera rastrear. Soporta categorías jerárquicas, parámetros personalizados, imágenes, notas y variantes.

  • Categorías y subcategorías ilimitadas
  • Parámetros y plantillas de parámetros
  • Piezas virtuales y de ensamblaje
  • Asociación a proveedores y fabricantes
  • Historial de cambios de precio
  • Archivos adjuntos y notas internas
📊

Stock — Control de Inventario

Gestiona las instancias físicas de cada Part. Cada StockItem representa una cantidad concreta en una ubicación específica, con trazabilidad completa.

  • Ubicaciones jerárquicas (almacén → estante → caja)
  • Historial completo de movimientos
  • Serialización de unidades individuales
  • Control de lotes y fechas de caducidad
  • Ajustes de stock con motivo registrado
  • Niveles mínimos de alerta
🏭

Build — Órdenes de Manufactura

Maneja el proceso completo de ensamblaje usando Bill of Materials (BOM). Permite planificar, asignar stock y registrar la producción de artículos ensamblados.

  • BOM con cantidades y tolerancias
  • BOM heredadas entre variantes
  • Asignación automática de stock
  • Seguimiento de órdenes de manufactura
  • Sub-ensamblajes en múltiples niveles
  • Control de outputs y rechazos
🛒

Order — Compras y Ventas

Módulo de gestión de órdenes de compra (PO) y órdenes de venta (SO), con ciclo de vida completo desde creación hasta recepción/entrega.

  • Purchase Orders con líneas de detalle
  • Sales Orders y órdenes de retorno
  • Recepción parcial de mercancía
  • Estados: borrador → emitida → recibida
  • Vinculación automática a stock al recibir
  • Historial de precios por proveedor
🏢

Company — Proveedores y Fabricantes

Registro centralizado de empresas relacionadas: proveedores, fabricantes y clientes, con información de contacto y referencias de partes.

  • Gestión de contactos y direcciones
  • SKU del proveedor por part
  • Precios de compra y tiempos de entrega
  • Monedas y condiciones de pago
  • Historial de órdenes por empresa
🧩

Plugin — Sistema de Extensiones

Arquitectura de plugins que permite extender InvenTree sin modificar el código fuente. Los plugins se activan desde la interfaz de administración.

  • Hooks en eventos del sistema
  • Endpoints personalizados en la API
  • Integración con barcode scanners
  • Notificaciones (email, Slack, webhooks)
  • Plugins oficiales: Digikey, Mouser, LCSC
  • Soporte para plugins de terceros via pip

API REST

Toda la funcionalidad de InvenTree está disponible vía API REST construida con Django REST Framework. La API está completamente documentada con OpenAPI 3.0 y cuenta con interfaz Swagger integrada accesible en /api/schema/swagger-ui/.

La autenticación soporta múltiples métodos: token Bearer, sesión de Django y Basic Auth. Todos los endpoints respetan el sistema de permisos por rol del sistema.

Módulo Endpoint base Métodos Descripción
Parts /api/part/ GET POST Listar y crear partes del catálogo
Part Detail /api/part/{id}/ GET PUT DEL Detalle, actualización y eliminación de una parte
Stock Items /api/stock/ GET POST Consulta y registro de items de stock
Stock Transfer /api/stock/transfer/ POST Mover stock entre ubicaciones
Build Orders /api/build/ GET POST Órdenes de manufactura / ensamblaje
Purchase Orders /api/order/po/ GET POST Órdenes de compra a proveedores
Companies /api/company/ GET POST Proveedores, fabricantes y clientes
Users /api/user/ GET Consulta de usuarios y permisos
BOM /api/bom/ GET POST Líneas de Bill of Materials

Seguridad y Permisos

InvenTree implementa un modelo de seguridad multicapa que separa autenticación de autorización, permitiendo un control granular sobre qué puede hacer cada usuario en cada módulo.

🔑

Autenticación

  • Sesión de Django (web UI)
  • Token Bearer (API REST)
  • Basic Auth (scripts y CI)
  • SSO via plugins (LDAP, OAuth2)
  • 2FA opcional mediante TOTP
🛡️

Autorización por Roles

  • Grupos de usuarios con permisos
  • Control por módulo: Part, Stock, Build, Order
  • Permisos: Ver / Crear / Editar / Eliminar
  • Superusuario administrativo
  • Acceso de solo lectura a API
🔒

Seguridad Adicional

  • CSRF protection en formularios
  • Rate limiting en API
  • HTTPS forzado en producción
  • Headers de seguridad HTTP
  • Auditoría de acciones críticas

Instalación con Docker

La forma recomendada de desplegar InvenTree en producción es mediante Docker Compose. El repositorio oficial incluye archivos de configuración listos para usar con Nginx, PostgreSQL, Redis y Celery.

1

Clonar el repositorio oficial

Descargar el código fuente desde GitHub al servidor de destino.

git clone https://github.com/inventree/InvenTree.git && cd InvenTree

2

Configurar variables de entorno

Copiar el archivo de ejemplo y ajustar credenciales de base de datos, clave secreta Django y correo.

cp .env.example .env && nano .env

3

Levantar los servicios con Docker Compose

Inicia todos los contenedores: web, worker Celery, base de datos PostgreSQL, Redis y Nginx.

docker compose up -d

4

Ejecutar migraciones y crear superusuario

Inicializa el esquema de base de datos y crea la cuenta de administrador.

docker compose run inventree-server invoke migrate

docker compose run inventree-server invoke superuser

5

Acceder a la interfaz web

InvenTree queda disponible en el puerto 80 por defecto. Iniciar sesión con las credenciales creadas en el paso anterior.

http://localhost/ → login con superusuario

Beneficios del Sistema

  • Centralización completa de inventario: un único punto de verdad para todas las partes y stock.
  • Trazabilidad end-to-end: desde la orden de compra hasta el ensamblaje final del producto.
  • API REST completa que permite integrar InvenTree con ERP, MES, sistemas de e-commerce o scripts internos.
  • Sistema de plugins extensible: se puede agregar lógica personalizada sin modificar el código núcleo.
  • Soporte para múltiples almacenes, ubicaciones anidadas y múltiples monedas.
  • Código abierto con licencia MIT: sin costos de licencia ni dependencia de un único proveedor.
  • Activa comunidad Open Source: bugs resueltos rápidamente, nuevas funciones constantes.
  • Despliegue reproducible con Docker garantiza comportamiento idéntico en dev y producción.
